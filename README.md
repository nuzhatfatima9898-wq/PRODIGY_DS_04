# Sentiment Analysis on Social Media Data✨

## Objective📌
Analyze sentiment patterns in social media data.

## Tools Used🔧🛠
- Python
- Pandas
- Matplotlib
- Google Colab
## Findings🔎
- Negative sentiment was the most common in the dataset.
- Positive sentiment was the second most common.
- Neutral sentiment accounted for a smaller portion of tweets.
- Irrelevant tweets were the least frequent.
- The analysis indicates that users expressed more negative opinions than positive ones.
